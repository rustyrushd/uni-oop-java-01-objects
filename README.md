# edu-oop-java-week_2

![A man in pink pyjamas looking at a laptop scratching his head in confusion with the caption "OOP vs POP"](oop_vs_pop.jpg)  

A simple demo calculator app that operates (+, -, *, /) on two numbers.

The app reads two numbers and a choice of operation from the user via an object created from the Scanner class. 
It then prints the result. Some errors are handled.

This repository is part of an evolving set of repositories (edu-oop-java-*) demonstrating coursework in OOP using Java.
The technologies used are Java, Maven, Git, GitHub and IntelliJ IDEA.
An internal programming style guide is used.
