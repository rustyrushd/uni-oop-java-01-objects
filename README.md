# edu-oop-java-week_2

![A cartoon character shrugging under the title "Object Orientated Programming (OOP) vs Procedural [Orientated] Programming (POP)"](oop_vs_pop.jpeg)  

This repository contains a single class in Java that reads two numbers and a choice of operation from the user via an object created from the Scanner class. 
The operations are addition, subtraction, multiplication and division. It then prints the result.
Simple but incomplete error correction is included.

This repository is part of an evolving set of repositories (edu-oop-java-week_x) demonstrating coursework in OOP using Java.
The technologies used are Java, Maven, Git, GitHub and IntelliJ IDEA.
An internal programming style guide is used.
